# منصة أميرة سليم

منصة تعليمية بسيطة مبنية على GitHub Pages + Supabase.

## طريقة الاشتراك الجديدة
1. الطالب ينشئ حسابًا ويسجل الدخول.
2. يختار الكورس ويحوّل قيمة الاشتراك إلى رقم التواصل: **01065461397**.
3. يضغط «الاشتراك في الكورس»، وسيتم فتح واتساب برسالة تأكيد.
4. الطلب يظهر في لوحة الإدارة.
5. بعد التأكد من التحويل، المدير يضغط «تفعيل».
6. يظهر الكورس للطالب، وإذا أضفت رابط المحاضرة في `video_url` يظهر له زر «فتح المحاضرة».

> المنصة لا تستقبل بيانات بطاقة أو أموال داخل الموقع؛ هي تعرض رقم التحويل وتسجيل طلب الاشتراك، ثم يتم التأكد من الدفع يدويًا قبل التفعيل.

## إعداد Supabase
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل ملف `supabase.sql` كاملًا.
3. افتح `config.js` وضع Project URL وPublishable/Anon key.
4. أنشئ أول حساب من `signup.html`.
5. في SQL Editor اجعل الحساب Admin:
   `update public.profiles set role='admin' where email='YOUR-ADMIN-EMAIL';`
6. افتح `admin.html` لإدارة الكورسات والطلاب وطلبات الاشتراك.

## GitHub Pages
ارفع الملفات نفسها إلى المستودع (لا ترفع ملف ZIP فقط)، ثم Settings → Pages → Deploy from a branch → main → /(root) → Save.


## نظام الاشتراك والدفع
- رقم التحويل الحالي: 01068980363.
- الطالب لازم يكون مسجل دخول بحسابه، وطلب الاشتراك يُحفظ مرتبطًا بمعرّف حسابه الداخلي `student_id`.
- في لوحة الأدمن يظهر اسم الطالب وبريده الإلكتروني والكورس المطلوب.
- عند الضغط على "تفعيل" يتم إنشاء سجل اشتراك (`enrollments`) لنفس `student_id` فقط، لذلك المحاضرة تظهر للحساب الذي وافقت عليه وليس لأي طالب آخر.
- رسالة واتساب تتضمن اسم الطالب وبريده الإلكتروني ورقم التحويل لتسهيل مطابقة التحويل.
